# Devpost Submissions

A tool developed for the [Hack-A-Ton With Friends](https://www.eventbrite.ca/e/hack-a-ton-with-friends-event-start-time-10am-tickets-1999716169895) hackathon to track and analyze Devpost submissions by scraping project metadata from linked git repositories (lines of code, commit history, first/last commits, ...).

## Required Dependencies
see contents of [flake.nix](./flake.nix)
- [uv](https://docs.astral.sh/uv/)
- [hurl](https://hurl.dev/) (optional)
